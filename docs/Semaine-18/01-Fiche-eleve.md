## 2️⃣ SLA (SERVICE LEVEL AGREEMENT)

### Définition Complète

> *"Accord contractuel entre fournisseur de service et client définissant les engagements de niveau de service, les responsabilités, les priorités et les recours en cas de non-respect."*

**SLA = Contrat de service**

---

### Structure d'un SLA

```
┌────────────────────────────────────────────────┐
│ 1. PÉRIMÈTRE                                   │
├────────────────────────────────────────────────┤
│ • Services couverts                            │
│ • Exclusions                                   │
│ • Horaires support                             │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ 2. OBJECTIFS DE PERFORMANCE                    │
├────────────────────────────────────────────────┤
│ • Temps de réponse (par priorité)             │
│ • Temps de résolution (par priorité)          │
│ • Disponibilité (uptime %)                     │
│ • Taux de résolution N1 (FCR)                  │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ 3. PRIORISATION                                │
├────────────────────────────────────────────────┤
│ • Matrice Impact × Urgence                     │
│ • Définition P1, P2, P3, P4                   │
│ • Exemples par priorité                        │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ 4. RESPONSABILITÉS                             │
├────────────────────────────────────────────────┤
│ • Obligations prestataire                      │
│ • Obligations client                           │
│ • Escalade hiérarchique                        │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ 5. MESURE & REPORTING                          │
├────────────────────────────────────────────────┤
│ • KPI suivis                                   │
│ • Fréquence reporting (mensuel)               │
│ • Comité de pilotage (trimestriel)            │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ 6. PÉNALITÉS / BONUS                           │
├────────────────────────────────────────────────┤
│ • Conditions déclenchement                     │
│ • Montants                                     │
│ • Plafond annuel                               │
└────────────────────────────────────────────────┘
```

---

### Exemple de SLA Complet

**EXTRAIT SLA — Support Informatique PME**

**Périmètre :**
- Support postes de travail (Windows, Mac)
- Support logiciels bureautiques (Office 365)
- Support réseau (WiFi, VPN)
- Exclusions : Matériel personnel, applications non validées

**Horaires :**
- Lundi-Vendredi : 8h-18h
- Hors horaires : Astreinte P1 uniquement

**Objectifs de performance :**

| Priorité | Réponse | Résolution | Disponibilité |
|----------|---------|------------|---------------|
| **P1** | 15 min | 4h | 99,9% |
| **P2** | 30 min | 8h | 99,5% |
| **P3** | 2h | 24h | 99% |
| **P4** | 1 jour | 5 jours | 98% |

**Pénalités (si non-respect SLA) :**
- P1 non respecté : -5% facturation mensuelle
- P2 non respecté : -2% facturation mensuelle
- Plafond annuel : 20% facturation totale

---

### Négociation d'un SLA

**Étapes de négociation :**

```
1. ANALYSE BESOINS CLIENT
   ├─ Quel est l'impact d'un incident ?
   ├─ Quelle est la criticité métier ?
   └─ Quel budget disponible ?

2. ÉVALUATION CAPACITÉS INTERNES
   ├─ Ressources disponibles (équipe)
   ├─ Outils (monitoring, ticketing)
   └─ Historique (taux résolution actuel)

3. PROPOSITION RÉALISTE
   ├─ SLA tenable (ne pas survendre)
   ├─ Aligné avec moyens
   └─ Marge de sécurité (80% capacité max)

4. NÉGOCIATION
   ├─ Écouter contraintes client
   ├─ Expliquer contraintes techniques
   └─ Trouver compromis gagnant-gagnant

5. FORMALISATION ÉCRITE
   ├─ Rédaction clause SLA
   ├─ Validation juridique
   └─ Signature contrat
```

**Principe clé :** **Mieux vaut under-promise et over-deliver** (promettre moins, délivrer plus) que l'inverse.

## 3️⃣ ENGAGEMENTS DE SERVICE

### Les 5 Piliers SERVQUAL

**Modèle de qualité de service :**

```
1️⃣ FIABILITÉ (Reliability)
   → Tenir ses promesses
   → Respecter SLA
   → Cohérence dans le temps

2️⃣ RÉACTIVITÉ (Responsiveness)
   → Répondre rapidement
   → Volonté d'aider
   → Traiter urgences en priorité

3️⃣ ASSURANCE (Assurance)
   → Compétence technique
   → Politesse
   → Inspirer confiance

4️⃣ EMPATHIE (Empathy)
   → Attention personnalisée
   → Écoute active
   → Comprendre contexte client

5️⃣ TANGIBILITÉ (Tangibles)
   → Documentation claire
   → Outils professionnels
   → Apparence professionnelle
```

**Mnémotechnique :** **F.R.A.E.T.**

## 4️⃣ GESTION DES ATTENTES CLIENTS

### L'Équation de la Satisfaction

```
┌────────────────────────────────────────────────┐
│                                                │
│  SATISFACTION = PERÇU - ATTENDU                │
│                                                │
│  Si Perçu > Attendu  → Client SATISFAIT ✅    │
│  Si Perçu = Attendu  → Client NEUTRE ⚠️       │
│  Si Perçu < Attendu  → Client INSATISFAIT ❌  │
│                                                │
└────────────────────────────────────────────────┘
```

**Stratégies :**

1. **Gérer l'attendu :**
   - SLA réalistes (ne pas survendre)
   - Communication claire (pas de promesses vagues)
   - Éduquer client (expliquer contraintes)

2. **Maximiser le perçu :**
   - Dépasser SLA quand possible
   - Communication proactive
   - Petites attentions (suivi post-résolution)

---

### Communication Proactive

```
❌ COMMUNICATION RÉACTIVE (à éviter)
   ├─ Attendre que client demande des nouvelles
   ├─ Répondre uniquement si sollicité
   └─ Résultat : Client anxieux, nombreux relances

✅ COMMUNICATION PROACTIVE (à privilégier)
   ├─ Donner des nouvelles AVANT que client demande
   ├─ Rythme : Toutes les 2-4h si incident long
   ├─ Exemple : "Point à 11h : Diagnostic en cours,
   │             résolution estimée 14h"
   └─ Résultat : Client rassuré, moins de relances
```

**Exemple de communication proactive :**

```
📧 EMAIL - 11h00

Objet : [Ticket #1234] Point d'avancement incident serveur

Je vous fais un point sur l'incident serveur en cours :

STATUT ACTUEL :
• Cause identifiée : Panne disque RAID
• Action en cours : Remplacement disque (livraison 13h)
• Prochaine étape : Reconstruction RAID (2h estimées)

RÉSOLUTION PRÉVUE : 15h30

Je vous recontacte à 13h30 pour confirmer réception disque.

En cas d'urgence : [numéro direct]

Cordialement,
[Signature]
```

## 5️⃣ MESURE DE LA SATISFACTION CLIENT

### Les 3 Indicateurs Principaux

```
┌────────────────────────────────────────────────┐
│ CSAT - Customer Satisfaction Score             │
├────────────────────────────────────────────────┤
│ Question : "Êtes-vous satisfait du service ?" │
│ Échelle : 1 à 5 étoiles                        │
│                                                │
│ Calcul : (Nb 4-5 étoiles / Total) × 100      │
│ Objectif : > 80%                               │
│                                                │
│ Quand mesurer : Après chaque ticket           │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ NPS - Net Promoter Score                       │
├────────────────────────────────────────────────┤
│ Question : "Recommanderiez-vous nos services ?"│
│ Échelle : 0 à 10                               │
│                                                │
│ Catégories :                                   │
│ • Détracteurs : 0-6 (insatisfaits)            │
│ • Passifs : 7-8 (neutres)                      │
│ • Promoteurs : 9-10 (ambassadeurs)            │
│                                                │
│ Calcul : % Promoteurs - % Détracteurs         │
│ Objectif : > 30                                │
│                                                │
│ Quand mesurer : Trimestriel ou annuel         │
└────────────────────────────────────────────────┘

┌────────────────────────────────────────────────┐
│ CES - Customer Effort Score                    │
├────────────────────────────────────────────────┤
│ Question : "Était-ce facile d'obtenir de      │
│             l'aide ?"                          │
│ Échelle : 1 (très difficile) à 5 (très facile)│
│                                                │
│ Calcul : Moyenne des scores                   │
│ Objectif : > 4/5                               │
│                                                │
│ Quand mesurer : Après interaction complexe    │
└────────────────────────────────────────────────┘
```

---

### Formules de Calcul

**CSAT (Customer Satisfaction Score) :**
```
CSAT = (Réponses positives / Total réponses) × 100

Exemple : 80 réponses 4-5 étoiles sur 100 réponses
→ CSAT = 80%
```

**NPS (Net Promoter Score) :**
```
NPS = % Promoteurs (9-10) - % Détracteurs (0-6)

Exemple :
50 promoteurs, 20 détracteurs, 30 passifs (sur 100)
→ NPS = 50% - 20% = +30
```

**Interprétation NPS :**
- NPS > 50 : Excellent
- NPS 30-50 : Bon
- NPS 0-30 : Moyen
- NPS < 0 : Mauvais (plus de détracteurs que promoteurs)

## 6️⃣ GESTION DES SITUATIONS DIFFICILES

### La Méthode ADER

**A.D.E.R. = Technique de communication client mécontent**

```
A - ACKNOWLEDGE (Reconnaître)
    "Je comprends votre frustration"
    "Vous avez raison d'être préoccupé"

D - DEFER (Différer si émotions trop fortes)
    "Prenez le temps de souffler"
    "On reprend dans 5 minutes ?"

E - EMPATHIZE (Faire preuve d'empathie)
    "À votre place, je serais frustré aussi"
    "Je mesure l'impact sur votre activité"

R - RESPOND (Répondre avec action)
    "Voici ce que je fais immédiatement :"
    [Action concrète + timing]
```

---

### Les 7 Règles d'Or

```
1. ÉCOUTER sans interrompre
2. RECONNAÎTRE le problème (pas nier)
3. S'EXCUSER si légitime
4. AGIR (pas promettre vaguement)
5. INFORMER régulièrement
6. TRANSFORMER en opportunité
7. SUIVRE après résolution
```
