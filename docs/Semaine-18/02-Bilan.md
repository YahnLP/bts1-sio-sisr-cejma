```
1. PÉRIMÈTRE

   ├─ Exclusions

2. OBJECTIFS DE PERFORMANCE
   ├─ Temps réponse (par priorité)

   ├─ Matrice Impact × Urgence

4. RESPONSABILITÉS
   ├─ Obligations prestataire
   ├─ Obligations client
   └─ Escalade hiérarchique

5. MESURE & REPORTING
   ├─ KPI suivis
   ├─ Fréquence reporting
   └─ Comité pilotage

6. PÉNALITÉS / BONUS
   ├─ Conditions déclenchement
   ├─ Montants
   └─ Plafond annuel
```

## ⚖️ L'Équation de la Satisfaction

```
╔════════════════════════════════════════════════════╗
║                                                    ║
║        SATISFACTION = PERÇU - ATTENDU              ║
║                                                    ║
║  Si Perçu > Attendu  → Client RAVI ✅             ║
║  Si Perçu = Attendu  → Client NEUTRE ⚠️           ║
║  Si Perçu < Attendu  → Client INSATISFAIT ❌      ║
║                                                    ║
╚════════════════════════════════════════════════════╝

STRATÉGIES :

1. Gérer l'ATTENDU (en amont)
   ├─ SLA réalistes (under-promise)
   ├─ Communication claire
   └─ Éducation client

2. Maximiser le PERÇU (pendant)
   ├─ Dépasser SLA si possible (over-deliver)
   ├─ Communication proactive
   └─ Petites attentions
```

## 📈 Les 3 Indicateurs Satisfaction

### Tableau Comparatif

| Indicateur | Question | Échelle | Calcul | Objectif |
|------------|----------|---------|--------|----------|
| **CSAT** | Satisfait ? | 1-5 ⭐ | (4-5 / Total) × 100 | > 80% |
| **NPS** | Recommanderiez-vous ? | 0-10 | % Promoteurs - % Détracteurs | > 30 |
| **CES** | Était-ce facile ? | 1-5 | Moyenne | > 4/5 |

---

### Formules (à retenir)

**CSAT (Customer Satisfaction Score) :**
```
CSAT = (Réponses 4-5 étoiles / Total réponses) × 100

Exemple : 80 satisfaits sur 100
→ CSAT = 80% ✅
```

**NPS (Net Promoter Score) :**
```
NPS = % Promoteurs (9-10) - % Détracteurs (0-6)

Exemple : 50% promoteurs, 20% détracteurs
→ NPS = +30 (Bon)

Échelle :
• NPS > 50 : Excellent
• NPS 30-50 : Bon
• NPS 0-30 : Moyen
• NPS < 0 : Mauvais
```

**CES (Customer Effort Score) :**
```
CES = Moyenne des scores (1-5)

Exemple : Total 410 points sur 100 réponses
→ CES = 4.1/5 ✅
```

## 🗣️ Communication Client : Méthode ADER

**A.D.E.R. = Technique client mécontent**

```
A - ACKNOWLEDGE (Reconnaître)
    "Je comprends votre frustration"
    "Vous avez raison d'être préoccupé"
    → Ne PAS nier le problème

D - DEFER (Différer si besoin)
    "Prenez le temps de souffler"
    "On reprend dans 5 minutes ?"
    → Si émotions trop fortes

E - EMPATHIZE (Empathie)
    "À votre place, je serais frustré aussi"
    "Je mesure l'impact sur votre activité"
    → Se mettre à la place du client

R - RESPOND (Répondre avec action)
    "Voici ce que je fais MAINTENANT :"
    [Action concrète + timing précis]
    → Pas de promesse vague
```

---

## 💬 Les 7 Règles d'Or Communication

```
1. ÉCOUTER sans interrompre
   → Laisser client exprimer frustration

2. RECONNAÎTRE le problème
   → "Je comprends", "C'est légitime"

3. S'EXCUSER si approprié
   → "Je vous présente nos excuses"

4. AGIR (pas promettre vaguement)
   → Action concrète + timing

5. INFORMER régulièrement
   → Communication proactive (toutes les 2-4h)

6. TRANSFORMER en opportunité
   → Insatisfaction = Amélioration

7. SUIVRE après résolution
   → Appel/email validation satisfaction
```

## 🔄 Boucle d'Amélioration Continue

```
    1. MESURER
    (CSAT, NPS, CES)
         ↓
    2. ANALYSER
    (Causes racines)
         ↓
    3. PLANIFIER
    (Plan d'action)
         ↓
    4. AGIR
    (Mise en œuvre)
         ↓
    5. COMMUNIQUER
    (Informer clients)
         ↓
   [Retour à MESURER]
```

**Principe :** PDCA (Plan-Do-Check-Act)

## ✅ Checklist Communication Proactive

```
☑ AVANT INCIDENT
  ├─ Informer maintenance planifiée (48h avant)
  ├─ Expliquer impact + alternatives
  └─ Confirmer compréhension

☑ PENDANT INCIDENT
  ├─ Première réponse : < 15 min
  ├─ Point avancement : Toutes les 2-4h
  ├─ Timing réaliste (pas optimiste)
  └─ Contact direct si urgence

☑ APRÈS RÉSOLUTION
  ├─ Validation satisfaction
  ├─ Explication cause
  ├─ Actions préventives
  └─ Remerciement patience
```

## 🤝 Négociation SLA : Les Étapes

```
1. ÉCOUTER demande client
   → Comprendre besoin réel

2. ANALYSER faisabilité
   ├─ Ressources disponibles
   ├─ Outils existants
   └─ Budget nécessaire

3. ÊTRE TRANSPARENT
   ├─ Expliquer contraintes
   ├─ Chiffrer (coût, délai)
   └─ Ne pas survendre

4. PROPOSER alternatives
   ├─ Option 1 : Dans budget actuel (optimisé)
   ├─ Option 2 : Avec surcoût modéré
   └─ Option 3 : Solution premium

5. TROUVER compromis gagnant-gagnant
```

**Principe :** **Under-promise, Over-deliver**  
(Promettre moins, délivrer plus)

## 💡 Situations Fréquentes & Réactions

### Situation 1 : Client furieux (SLA dépassé)

**❌ À ÉVITER :**
- "Ce n'est pas de ma faute"
- "Calmez-vous"
- Justifications techniques immédiates

**✅ À FAIRE :**
1. Écouter sans interrompre
2. Reconnaître + S'excuser
3. Expliquer situation (factuel)
4. Donner timing précis
5. Engager communication régulière

---

### Situation 2 : Demande impossible (budget)

**❌ À ÉVITER :**
- "Impossible"
- "Jamais vu ça"
- Accepter en sachant qu'on ne peut pas

**✅ À FAIRE :**
1. Comprendre besoin sous-jacent
2. Expliquer contraintes (transparent)
3. Proposer 2-3 alternatives
4. Chiffrer chaque option
5. Laisser client décider

---

### Situation 3 : Client se plaint toujours

**❌ À ÉVITER :**
- "Vous exagérez"
- "Ce n'est pas si grave"
- Être sur la défensive

**✅ À FAIRE :**
1. Reconnaître fréquence anormale
2. Proposer audit complet
3. Plan d'action préventif
4. Suivi rapproché temporaire
5. Transformer en opportunité (fidélisation)
