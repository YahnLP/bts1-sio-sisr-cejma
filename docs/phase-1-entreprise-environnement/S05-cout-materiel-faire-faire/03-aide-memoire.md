# Aide-mémoire – Coûts, TCO, faire ou faire-faire, garanties

*BTS SIO SISR 1re année – CEJMA – S05*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Coûts et productivité

- **Coût fixe** / **variable** / **complet** / **moyen**.
- **Seuil de rentabilité** = coûts fixes ÷ (prix − coût variable unitaire).
- **Productivité** = production ÷ facteur utilisé. Si le temps est divisé par k, la productivité est multipliée par k.

## Chaîne de valeur (Porter)

**Principales** : logistique interne, production, logistique externe, commercial, services. **Soutien** : infrastructure, ressources humaines, technologie, achats.

## Faire ou faire-faire

Critères : **compétence** (cœur de métier), **coût**, **risque** (données sensibles, dépendance), **flexibilité**, **qualité** (contrôle par SLA).

## TCO

**TCO = achat + installation + (maintenance + énergie) × durée + remplacements − reprise.** Coût annuel = **TCO ÷ durée d'usage**.

## Cadre juridique

| Sujet | À retenir |
|---|---|
| Garantie légale de **conformité** | Consommateurs : 2 ans (bien neuf) |
| **Vices cachés** | Professionnels aussi ; articles 1641 et suivants du Code civil ; 2 ans après la découverte |
| **Obsolescence programmée** | Délit (art. L441-2 Code de la consommation) ; 2 ans et 300 000 € |
| **Réparabilité / durabilité** | Note sur 10 ; durabilité remplace progressivement la réparabilité (à partir de 2025) |
| **DEEE** | Producteur finance ; distributeur reprend « un pour un » |

## Pièges

- Comparer des **coûts totaux** sur des **durées différentes** : ramener à l'**année**.
- Confondre **consommateur** et **professionnel** (garanties différentes).
- Appeler « obsolescence programmée » toute panne : il faut une **intention** de réduire la durée de vie.
