# FICHE TP - S20 Année 1 - CEJMA
## TP : Analyse Approfondie de Situations Juridiques Vécues

---

## Informations Générales

| **Champ** | **Détail** |
|-----------|-----------|
| **Durée** | 60 minutes |
| **Format** | Travail en îlots (4-6 apprentis par îlot) |
| **Objectif pédagogique** | Analyser en profondeur 2 situations juridiques vécues selon la méthode QQOQCP |
| **Matériel** | Grille QQOQCP (1 par situation), cas complémentaires si nécessaire |

---

## Objectif du TP

**Approfondir l'analyse** de situations juridiques identifiées dans l'activité de découverte en utilisant la **méthode QQOQCP juridique** et en mobilisant les connaissances de l'Année 1.

---

## Phase 1 : Sélection des Situations (10 min)

### Consigne Îlot

> "En groupe, sélectionnez **2 situations juridiques** parmi celles identifiées lors de la cartographie (activité de découverte). Choisissez :
> - **Situation 1** : Une situation **fréquemment vécue** par plusieurs membres de l'îlot (ex: installation de logiciels, création de comptes)
> - **Situation 2** : Une situation **problématique ou complexe** qui a posé question (ex: demande illégale du tuteur, incident de sécurité)"

### Critères de Sélection

✅ **Situation concrète** et vécue en entreprise (pas théorique)  
✅ **Enjeu juridique identifiable** (lien avec les 6 familles)  
✅ **Suffisamment détaillée** pour permettre une analyse (contexte disponible)  
✅ **Diversité** : Les 2 situations doivent relever de familles juridiques différentes

### Si l'Îlot Manque de Situations

**L'enseignant fournit des "Cas Complémentaires Types"** (voir Annexe ci-dessous) adaptés au type d'entreprise de l'îlot.

## ANNEXE : Cas Complémentaires Types (par Type d'Entreprise)

### Cas Type 1 — PME < 50 Salariés

**Situation :** "Le dirigeant de l'entreprise vous demande d'installer un logiciel de surveillance des emails des salariés pour 'vérifier qu'ils ne passent pas leur temps sur leur boîte perso'. Aucune charte informatique n'a été signée."

**Famille juridique :** 🟡 Droit du travail IT + 🟢 RGPD

**Enjeux :**
- Code du Travail Art. L1121-1 : Respect de la vie privée du salarié
- RGPD Art. 5 : Licéité du traitement, minimisation des données
- Absence de charte = absence d'information préalable (illégal)

**Action attendue :**
1. Alerter le dirigeant de l'illégalité de la surveillance sans information préalable
2. Proposer de rédiger une charte informatique définissant l'usage acceptable
3. Informer/consulter les représentants du personnel si existants
4. Si surveillance nécessaire : limiter aux seuls emails professionnels, durée limitée, finalité précise

---

### Cas Type 2 — Grande Entreprise

**Situation :** "Vous êtes junior admin système. Lors d'une maintenance, vous découvrez que la base de données clients (50 000 fiches avec nom, adresse, email, historique achats) n'est pas chiffrée. Vous signalez à votre N+1 qui vous répond : 'On sait, mais le chiffrement ralentit les requêtes. On verra ça plus tard.'"

**Famille juridique :** 🟢 RGPD + 🔴 Responsabilité & Sécurité

**Enjeux :**
- RGPD Art. 32 : Obligation de sécurité (chiffrement recommandé pour données sensibles)
- Risque de sanction CNIL en cas d'incident
- Responsabilité pénale si faille exploitée

**Action attendue :**
1. **Tracer l'alerte par écrit** (email à N+1 + copie à votre boîte perso)
2. Proposer des solutions techniques : chiffrement à la volée (TDE), chiffrement applicatif, chiffrement des sauvegardes
3. Argumenter le risque : sanction CNIL (jusqu'à 4% CA), impact réputationnel, responsabilité pénale
4. Remonter au RSSI ou DPO si N+1 maintient sa position

---

### Cas Type 3 — ESN / SSII

**Situation :** "Vous êtes en mission chez un client. Le client vous demande de récupérer tous les emails d'un salarié qu'il soupçonne de vouloir partir à la concurrence, sans en informer le salarié. Le client est votre employeur indirect (il paie votre ESN)."

**Famille juridique :** 🟡 Droit du travail + 🟢 RGPD + 🔴 Responsabilité

**Enjeux :**
- Code du Travail Art. L1121-1 : Interdiction de surveillance clandestine
- RGPD Art. 5 : Licéité du traitement
- Code Pénal Art. 226-15 : Atteinte au secret des correspondances (délit)

**Action attendue :**
1. **Refuser** d'exécuter la demande (elle est illégale)
2. Expliquer au client que cette action constitue un délit pénal
3. Proposer une alternative légale : procédure RH contradictoire avec information du salarié
4. Alerter votre hiérarchie ESN de la demande client (traçabilité)

---

### Cas Type 4 — Collectivité Publique

**Situation :** "La collectivité lance un appel d'offres pour renouveler son parc de 200 PC. Le cahier des charges impose 'Windows 11 Pro pré-installé'. Un élu écologiste vous interroge : 'Ne pourrait-on pas utiliser Linux pour réduire les coûts et l'impact environnemental ?'"

**Famille juridique :** 🟣 Économie & Régulation + 🔵 Propriété intellectuelle

**Enjeux :**
- Code de la Commande Publique : Neutralité technologique (pas de mention de marque)
- Licences propriétaires vs open source : comparaison TCO (Total Cost of Ownership)
- Compatibilité avec l'écosystème existant

**Action attendue :**
1. **Corriger le cahier des charges** : remplacer "Windows 11 Pro" par "Système d'exploitation compatible avec les logiciels métiers utilisés"
2. Réaliser une étude comparative : Windows vs Linux (coût licences, formation, compatibilité)
3. Si migration Linux envisagée : prévoir phase pilote (10-20 postes), formation utilisateurs
4. Argumenter objectivement les avantages et inconvénients (technique + économique + juridique)

## Éléments de Correction Attendus

### Exemple d'Analyse QQOQCP — Cas PME (Surveillance Emails)

| **QQOQCP** | **Réponse Attendue** |
|------------|----------------------|
| **QUI ?** | Dirigeant (donneur d'ordre), apprenti (exécutant technique), salariés (personnes surveillées) |
| **QUOI ?** | Mise en place d'une surveillance des emails salariés sans information préalable |
| **OÙ ?** | Serveur de messagerie de l'entreprise (France) |
| **QUAND ?** | Demande immédiate — aucun délai légal spécifique mais urgence de conformiser |
| **COMMENT ?** | Installation d'un logiciel de monitoring (ex: MailStore, surveillance Exchange) |
| **POURQUOI ?** | Suspicion d'utilisation abusive — Protection de l'employeur vs Respect vie privée salarié |
| **Qualification** | Droit du travail (CT L1121-1) + RGPD (Art. 5 licéité) |
| **Textes** | Code du Travail Art. L1121-1, RGPD Art. 5, Délibération CNIL sur cybersurveillance |
| **Actions** | 1. Rédiger charte informatique 2. Informer salariés 3. Limiter surveillance (proportionnalité) |

## Points de Vigilance Enseignant

### Gérer les Débats Juridiques

**Situation fréquente :** Les apprentis débattent sur "ce qui est légal ou non" et arrivent à des conclusions divergentes.

**Posture enseignant :**
1. ✅ **Valoriser le débat** : "C'est exactement ce que font les juristes professionnels."
2. ✅ **Arbitrer avec les textes** : "Allons vérifier ensemble dans le RGPD Art. X..."
3. ✅ **Montrer la nuance** : "En droit, il y a souvent une zone grise. L'important est d'argumenter."
4. ❌ Éviter : "C'est faux, vous n'avez rien compris." → Dévalorisant et ferme la réflexion

### Valoriser les Analyses Complètes

**Technique :** Lors de la restitution (Phase 4), l'enseignant sélectionne **2 îlots** pour présenter :
- 1 îlot ayant eu une **analyse particulièrement complète** (toutes les cases QQOQCP remplies)
- 1 îlot ayant traité une **situation particulièrement complexe**

→ Valorisation publique : "Bravo, votre analyse est de niveau professionnel."
