# Phase 2 – Organisation, risques et financement

**Séances S06 à S10.** Choisir une structure juridique, répondre aux risques (responsabilités civile et pénale), organiser un service de support, gérer les incidents et comprendre comment une entreprise se finance.

> [!NOTE]
> Chaque séance de 4 h contient une **fiche séance**, un **cours**, une **étude de cas** avec dossier documentaire et un **aide-mémoire**. Les séances marquées *à valider* ont été écrites lors de la refonte : elles attendent la relecture de l'enseignant.
