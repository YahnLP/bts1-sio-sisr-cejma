> [!NOTE]
> **Question qui guide la séance :** *« Quand un incident se produit, qui répond de quoi : l'entreprise, le dirigeant, l'administrateur ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Distinguer **responsabilités civile, pénale et disciplinaire**
2. Vérifier les **trois conditions** de la responsabilité civile
3. Citer les principales **infractions informatiques** et leurs peines
4. Qualifier une **faute disciplinaire**
5. Décrire comment un **administrateur** se protège

Existe-t-il une procédure d'alerte de sécurité dans ton entreprise ? Qui décide quand un risque est signalé ? Note comment la décision est tracée.
