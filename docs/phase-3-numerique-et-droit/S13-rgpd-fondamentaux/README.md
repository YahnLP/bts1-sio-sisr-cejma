> [!NOTE]
> **Question qui guide la séance :** *« Qui est responsable des données personnelles et selon quels principes peut-on les traiter ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Définir **donnée personnelle** et **donnée sensible**
2. Distinguer **responsable**, **sous-traitant**, **DPO**, **CNIL**
3. Citer les **principes** de l'article 5
4. Associer une **base légale** à une finalité
5. Lister les **outils** de conformité

## Retour en entreprise

Repère dans ton entreprise un formulaire qui collecte des données : l'information donnée est-elle suffisante (identité, finalité, durée, droits) ?
