> [!NOTE]
> **Question qui guide la séance :** *« Quels droits ont les personnes sur leurs données et comment l'entreprise doit-elle y répondre ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Citer les **droits** des personnes
2. Appliquer les **délais** de réponse
3. Évaluer une **bannière cookies**
4. Distinguer les règles de **prospection**
5. Repérer un **transfert hors UE**
