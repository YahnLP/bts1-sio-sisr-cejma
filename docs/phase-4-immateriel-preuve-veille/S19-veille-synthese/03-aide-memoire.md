# Aide-mémoire – Veille et méthode de réponse

*BTS SIO SISR 1re année – CEJMA – S19*

> Un mot ou un sigle inconnu ? Passe la souris dessus, ou ouvre le [glossaire](../../ressources/glossaire.md).

## Veille

Besoins → sources → collecte → tri → synthèse → action → évaluation.

**Sources** : Légifrance, EUR-Lex, CNIL, ANSSI/CERT-FR, Cybermalveillance, INPI, Insee, Bpifrance Création.

**Bulletin** : fait · source · impact · action.

## Méthode face à un dossier

| Étape | Réflexe |
|---|---|
| Lire le sujet | Contexte, questions, points |
| Lire le dossier | Faits, chiffres, dates |
| Repérer le thème | Économie, droit, management |
| Répondre | **Notion → application → conclusion** |
| Citer | « Selon le document… » |
| Calculer | Formule, calcul, **unité**, commentaire |
| Relire | Chiffres, orthographe |

## Calculs utiles

- Coût total = somme des postes.
- Écart (%) = écart ÷ coût de référence × 100.
- Disponibilité = 1 − (indisponibilité ÷ durée totale).

## Pièges

- Répondre sans citer le dossier.
- Oublier l'unité.
- Confondre notion et application.
