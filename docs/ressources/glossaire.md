# Glossaire

Les mots et sigles du cours, expliqués simplement. Dans les pages du site, **passe la souris sur un sigle** (ESN, SLA, RGPD…) : sa définition s'affiche.

La colonne « Vu en » indique la séance où le mot apparaît pour la première fois dans le cours.
